# Asset provenance

All five website/repository previews are screenshots of actual public pages, captured 2026-09-08 using Chromium at 1440 × 1000. Original evidence is in `docs/evidence/current-*.png`; optimized derivatives in `public/projects/`. These are project previews, not invented interfaces or AI-generated assets.

- Olive Aesthetics: https://oliveaestheticsclinic.com
- MaxsReviews: https://maxsreviews.co.uk
- AI DDoS Firewall: https://github.com/JackCoates1/AI-DDOS-Firewall
- Insecurity Multi-Tool: https://web.whop.com/insecurity-ships/exp_EHYo1MBwGigTZP/app/
- Portfolio: https://jackcoates.co.uk (the original production design, labelled accordingly)
- Homelab: there is no supplied hardware photo or public dashboard. `docs/design/homelab-architecture.svg` is an explicitly labelled diagram of the documented real systems, rendered to WebP. It is not a screenshot and does not imply an exact physical/network topology. Private IPs and unrelated client services are omitted. A real hardware photo would be a valuable later replacement.

Globe geography: Natural Earth 1:110m land polygons, public domain, from https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_land.geojson . `scripts/telemetry/build-land.py` creates the local point/coast dataset. Natural Earth terms: https://www.naturalearthdata.com/about/terms-of-use/ . Geography is independent of the observed security origins.

Typography: self-hosted Outfit (Google Fonts / Rodrigo Fuenzalida) and IBM Plex Mono (IBM), SIL Open Font License. License files accompany the fonts in `public/fonts/`. No external font calls.

The Insecurity preview was recaptured after waiting for the real app content to load (`docs/evidence/insecurity-app.png`). The first capture only showed the loading shell and was rejected during critique. No product stats were transcribed into portfolio claims.
